## Cara memakai:
1. git clone <url>
2. composer install
3. cp .env.example .env
4. edit .env bagian
   DB_CONNECTION=mysql
   DB_HOST=<isi nama container db>
   DB_PORT=3306
   DB_DATABASE=isi
   DB_USERNAME=isi
   DB_PASSWORD=isi
